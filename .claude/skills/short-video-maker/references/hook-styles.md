# フック型ライブラリ — 最初の1秒の設計

ショート動画の勝負は最初の1秒。フックは「型」で作り、**素材の意味で型を選ぶ**。

マンネリの正体は「ポーズ以外の全変数(背景・構図・色・文字演出・動き)が固定」であること。型×背景×動きの組み合わせで回す。

## 5つの型(素材の意味で選ぶ)

| 型 | Scene指定 | 向く素材 |
|---|---|---|
| A キーアート | `type:'typo', bg:'shu', src:'<透過決め絵>.png', slam:true` | 警告・断言 |
| B 動画先行 | `type:'typo', videoSrc:'<Bロール>.mp4'` | 体験談・見せ物がある回 |
| C 巨大数字 | `type:'number', num:'300万円', numLabel:'<前置き>', text:'<オチの一文>', slam:true, bg:'mono'` | 金額・数量の衝撃 |
| D 対比2分割 | `type:'split', src/srcB, labelA/labelB` | ビフォーアフター・二択 |
| E 漫画コマ | `type:'manga', src:'<白バック漫画調>.png', slam:true` | あるある・自虐 |

**選定の掟: 直近2本と同じ型を使わない。** 型の履歴を残して輪番させる。

**C型の掟: 数字だけでは半分。** `text`(オチの一文)まで入れて初めて刺さる(「1億円」だけでは事実、「1億円/使い切りました」で事件になる。実測FB)。前置き=numLabel・オチ=text+slamの三点セットが完成形。

## 背景プリセット(bg)

コード描画なので素材不要。typo/number/split/mangaの下に敷ける。

**掟: 本編のtypoカードにも必ずどれかを敷く。** bgなしの素の暗背景は画面の下2/3が空白になり「背景が入っていない」ように見える(実測フィードバック)。選び方も素材の意味で: 断言・パンチライン=shu / 速度・事件性=mono / 告白・文化系=washi。同じ動画の中では並びが単調にならないよう型を回す。

- `shu` — 朱ベタ×黒集中線。漫画の見開き感。警告・断言に
- `mono` — 暗地×白速度線。スピード感。数字・事件性に
- `washi` — 和紙×金の雲文。上品・文化系に(文字は自動で墨・深色に落ちる)

## 動きの演出

- `flash: true` — カット頭の白フラッシュ1発(4Fで減衰)。切替の衝撃に
- `slam: true` — 一文字ずつ叩き付け+ドン1発自動。断言のタイポに(「|」は不要。slamに生の「|」を混ぜると露出する)
- `jitter: true` — 静止素材の微振動。「止まってる感」を消す
- どどど「|」 — 塊ごとの順ポップ+塊数ぶんのドン自動。cue字幕と非slamタイポのみで使う

## 決め絵(キャラの一撃ポーズ)の作り方

1. キャラの正典1枚を参照画像にして、画像生成AI(編集モード)でポーズ違いを生成する。**参照は常に正典の1枚**(生成物を次の参照にしない。世代を重ねると顔が変わる)
2. **単色背景(緑)で生成→クロマキー透過**が確実。白背景からの自動切り抜きは輪郭が汚れる
3. 透過後のQC: 暗背景に重ねて縁の色残りを目視+ピクセル検査
3b. **透過後は実質バウンディングボックスで余白をトリムする(実測)**: 決め絵は「下端アンカー・表示高さ固定」で据えるため、上の透明余白が残っているとキャラがその分小さく・下に沈む。クロマキー後は微小なアルファノイズが混ざるので、`getbbox()`でなく しきい値つき(例: alpha>24 の画素が3個超の行/列)で実質bboxを取り、左右+上を数pxパディングでcropしてから使う。文字ゾーンは画像側の余白でなく`textPos:'top'`で確保する
4. **上1/3を文字用に空けた構図**をプロンプトで明示する(でか文字と喧嘩しない)
5. 喋っている区間に使うフックは開口(口が開いた表情)の絵にする

ポーズの語彙(素材の意味→ポーズ対応の目安): 指突きつけ=警告 / 見開き驚き=衝撃 / 腕組み=断言 / ひらめき=方法・解決 / 内緒口元=秘密 / 万歳=成果。エンドCTAだけは毎回同じ決め絵で固定する(ブランド記憶を揃える)。

## Bロールの型(本編の画変わり)

1. 静止画生成(photorealistic)。**人物は後ろ姿・顔なしを明示指定**(「seen strictly from behind」+「画面内のスマホ・TVにも顔を出さない」まで書くと安定する)
2. 1枚ずつ目視検収
3. 動きが要る場面だけimage-to-video(480p・4秒)→ローカルアップスケール×2
4. 動きが要らない場面は静止画のままKen Burns(`type:'still'` + kb)が最安
5. **Bロールは使い回さず都度生成**(マンネリの温床)。服装・小物の「アンカー」(例: 同じ帽子・同じパーカー)を決めてプロンプトに毎回入れると、別カットでも同一人物に見える
6. **紙幣・書類・画面を描かせると「実在風の肖像」と「読める数字」が勝手に入る(実測)**: 漫画調のお札にも諭吉風の顔と額面が描き込まれ、意図しない顔+嘘の字の二重アウトになる。金の話の素材は「completely blank stylized bills, no portraits, no digits, no readable characters」のように**無地を明示指定**する。写実の札束は「blurred」指定+目視で判定
