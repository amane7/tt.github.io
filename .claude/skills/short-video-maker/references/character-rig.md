# キャラリグ — 自分のキャラを口パクさせる

CharacterShort.tsx はキャラ固有値を一切持たない。**キャラの情報はすべて character.json に集める**(assets/character.template.json から作る)。このファイルはその作り方。

## 素材の構成(レイヤー分解)

キャラ画像を**同一寸法のPNG(透過)2〜3枚**に分解する。全レイヤーが同じキャンバスサイズで、重ねるとキャラが完成する状態にする。

| ファイル | 内容 | 必須 |
|---|---|---|
| body | 胴体(首から下+髪の後ろ側など、頷きで動かない部分) | ✅ |
| head | 頭・顔(**口は描かない**。口はコードがSVGで描画する) | ✅ |
| eyeLid | 瞼パッチ(目の領域だけを肌色・瞼で塗った差分。瞬き用) | 任意 |
| bodyPoint / bodyOpen | 指差し・両手広げのポーズ差分胴体 | 任意 |
| handPoint | 指差しの手だけを切り出したレイヤー(頭より手前に重ねる) | 任意 |
| hookBase | 全身1枚絵(numberフックの下端で使う) | 任意 |

- 分解は画像編集ツールでもAI(インペイント・領域塗り)でもよい。**口を消した頭**を作るのが唯一の必須加工
- ポーズ差分を作らない場合、gesture指定は静かに無効化される(エラーにはならない)
- 元絵が1枚しかなく分解が難しい場合の最小構成: bodyを透明画像にして、headに全身を入れる(頷きで全身が揺れるが成立はする)
  - **⚠この構成ではdisplayHeightの引き上げが必須**(実測): 既定値620はバストアップ肖像レイヤー前提の値で、全身1枚をheadに入れると画面中央に極小のキャラが浮く。**全身1枚構成の目安は1100〜1300**。faceCenterRatioも「顔中心のy ÷ 画像の高さ」で計り直す(後光リングの中心がずれる)。調整後は必ず静止画QCでキャラの画面占有を確認する

## 座標計測(Claudeがやる。ユーザーに測らせない)

character.json の座標はすべて**キャラ画像のネイティブピクセル座標**。Claudeがキャラ画像をReadで読み、以下を目測→検証スクリプトで確定する:

1. **canvas**: 画像の実寸(ImageMagick `identify` 等で機械取得)
2. **mouth.cx / mouth.top**: 口の中心Xと、開いた口の上端Y(口を消した位置の中心)
3. **eyes[]**: 左右の目の中心座標
4. **headPivot**: 首の付け根(頷きの回転軸。顎の下・首の中心)
5. **cheeks[]**: 頬紅を置く位置(目の斜め下)

**計測の検証は必ず「印付き画像」で行う**: 計測した座標に十字マークを描いた確認画像をスクリプトで合成し、Claudeが自分で目視して口・目・首とズレていないか確かめる。ズレたまま進むと口が顎や鼻に描かれる。

```bash
# 例: ImageMagickで計測点に十字を打って確認画像を作る
magick char-head.png -stroke red -strokewidth 4 \
  -draw "line 290,450 310,450 line 300,440 300,460" work/rig-check.png
```

## 色の設定

- mouth.fill / tongue / line: 口内・舌・輪郭線の色。キャラの画風に合わせる(線の色は目・口とも共通で使われる)
- eyePatch.color: eyeLid画像を作らない場合に瞬きで目を塗りつぶす色。**キャラの肌色をスポイトで拾う**
  - **⚠️目の周りが多色のキャラ(動物の毛柄・模様・濃い隈取り等)は単色パッチだと縁が浮く**(実測: 柴犬キャラで発生)。この場合は**eyeLid専用画像を作るのが正**——頭画像の目周りをコピーし、目だけ閉じ状態に描き替えた同サイズPNG(PILで目領域に周辺の毛色を延長するだけでも成立)。stern/sadの半目パッチも同じ色を使うため、多色顔では表情カタログQC(7種)で縁の浮きを必ず確認する
- cheekColor: 頬紅の色

## 口パクの仕組みと調整

- 口は「閉じ=微笑線 / 開き=D型+舌」をSVGで描画し、音声のRMSに連動して開閉する
- 開き幅・高さの基準値(mw 54〜100 / mh 7〜63)はキャンバス600x900級のキャラを想定。**キャラが極端に大きい/小さい場合はCharacterShort.tsxの該当定数を比例調整**する
- RMS閾値(0.006で開き始め/0.116でフル)は素材依存。最初の1本で必ずキャリブレーション(quality-gates.md)
- **表情もすべてコード描画**(mood 7種: smile/laugh=にっこり目+口角上げ+頬紅 / stern=眉ひそめ+半目+への字+舌なし / sad=八の字眉+への字 / serious=直線口+フラット眉 / wink=片目∩)。**表情用の追加素材は不要**——眉・まぶたは目の座標(eyes)から自動配置される。眉が濃いキャラ絵は二重眉に見えないか最初の1本のQC静止画で確認し、ずれる場合は各表情描画ブロックのオフセットを調整する。**新キャラの初回は表情カタログのQC静止画を7種ぶん撮って一括目視する**(モックのcuesに各moodを4秒間隔で並べるだけでよい)

## テーマ(ブランド色)の差し替え

色は theme プロップで注入する。既定はダーク地×金アクセント。差し替えるのは4値だけ:

```ts
const myTheme = { bg: '#0b0e14', ink: '#f2efe8', accent: '#d9b36a', font: '"Hiragino Sans", sans-serif' };
```

- accentは強調文字・後光・プログレスバーに共通で効く。**ブランドの1色に絞る**(複数色はうるさくなる)
- 和紙背景(bg:'washi')のときだけ文字が自動で墨色・深色に落ちる(明地に明色は沈むため)

## キャラ絵を新規に作る場合

1. 画像生成AIで「正面向き・立ち姿・シンプルな背景」のキャラを生成する。**口を閉じた(または口のない)顔**を指定すると分解が楽
   - **⚠「口を描くな」指示は無視されがち**(実測: "no mouth drawn"明示でも鼻+口が描かれた)。口はコード描画なので、**元絵に口が残ったらPILで肌色パッチを当てて必ず消す**(残すと口パクと二重口になる)。同様に目の開閉も上書き描画なので、目は「開き目」で生成しておく
2. スタイル統一のため、決め絵・ポーズ差分は**最初の1枚を参照画像にして同一セッションで**生成する(生成物を参照に連鎖させない。参照は常に正典の1枚)
3. 背景の除去は生成時に単色背景を指定→クロマキーが確実。除去後は暗背景に重ねて縁の残渣を目視確認
4. 和装キャラを左右反転して使わない(着物の合わせが左前=死装束になる)。反転が必要なら右前を明記して再生成する
